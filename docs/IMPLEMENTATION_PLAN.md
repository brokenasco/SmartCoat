# SmartCoat execution plan

## Assessment (2026-07-22)

The supplied workspace was empty: no source code, database, authentication, tests, documentation, deployment configuration, or Git history existed. A greenfield Next.js App Router and Supabase architecture was therefore selected. Foundation and estimating integrity are prioritized before broad feature count.

## Stages

1. **Foundation — implemented:** strict TypeScript app, responsive design tokens, environment validation, Supabase SSR session handling, tenant schema, roles, RLS, explicit API grants, auditing tables, CI, and unit tests.
2. **Estimating vertical slice — implemented:** room measurement, opening deductions, paint rounding, loaded labor, overhead, target margin, tax, deposit, immutable calculation snapshots, authenticated save, and tenant-scoped dashboard.
3. **Company operations — next:** progressive onboarding, invitations, CRM CRUD, property condition media, catalogs, permission administration.
4. **Production and finance — next:** estimate approval/versioning, proposal PDF, project conversion, assignments, mobile field status, inspections, change orders, invoices, payment allocation.
5. **Commercial launch — next:** Stripe/Resend, customer portal, storage policies, reporting, admin support workflow, monitoring, performance/accessibility/E2E audits.

See `docs/LAUNCH_READINESS.md` for the honest completion boundary and blockers.
